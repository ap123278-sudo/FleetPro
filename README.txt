Fleet Manager MVP 0.1
======================
Included: Fleet_Manager_MVP.html

How to try it on Android:
1. Download Fleet_Manager_MVP.html to your phone.
2. Open it with Chrome or another modern browser (if the phone asks, choose a browser).
3. Register a vehicle, then add income/expense entries.
4. Use Backup > Download Backup regularly.

Important:
- This is an offline-first browser prototype, not a signed Android APK.
- Data is stored in the browser on that device. Clearing browser storage can remove it.
- Backup/restore uses a JSON file.
- Cloud sync, user login, automated bank-grade loan amortization, and Play Store packaging are not implemented yet.
- Profit is an estimate based on entered income, operating expenses, and separately recorded interest. For accurate loan balance, record principal repayments separately.
